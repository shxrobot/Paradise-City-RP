# 🌴 PARADISE CITY RP - Website

Sito ufficiale per Paradise City RP - Emergency Hamburg Roleplay.

**Link Discord:** https://discord.gg/H9bHzC3wXS

## Deploy su GitHub Pages
1. Crea repo `paradise-city-rp`
2. Carica `index.html`, `style.css`, `script.js`
3. Settings > Pages > Deploy from main branch
4. Fatto.

## Personalizzazione
- Logo: cerca `PARADISE CITY` in index.html
- Colori: modifica :root in style.css
- Avatar Founder: sostituisci <div class="founder-avatar">S</div> con <img src="assets/founder.png">
- Regolamenti: già completi, editabili in index.html sezione #regolamenti

## Features
- Preloader, particelle, mouse glow, tilt 3D, glassmorphism, scroll progress, reveal
- Responsive, mobile-first, no backend
